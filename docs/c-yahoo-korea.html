이어진 것

RAC와 Data Guard는 가용성 설계의 초기 형태였습니다. 노드 장애와 사이트 장애를 구분해서 다루는 관점 — Active와 Standby를 나누는 사고방식이 여기서 시작됐고, 트렌비의 Zone Active / Region Standby 판단까지 이어집니다.

본사 기준을 지역에서 이행하고 결과를 보고하는 구조는 이후 ISMS-P 심사 대응에서 쓰게 되는 "기준 항목에 대해 근거를 갖춰 답한다" 는 작업 방식의 출발점입니다.
