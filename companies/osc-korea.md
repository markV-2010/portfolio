## 이 시기의 상황

CNCF Landscape에는 프로젝트가 계속 늘고 있었지만, 국내에서 상용 환경에 적용된 사례는 드물었습니다.
"쓸 수 있는가"를 판단할 근거가 없었습니다.

## 맡은 범위

상용 검증이 끝나지 않은 기술을 먼저 시험하고, 국내 고객사가 쓸 수 있는 형태로 옮기는 일.

## 주요 업무

**CNCF (Linux Foundation) 생태계**

- Kubernetes 오픈소스 인큐베이터 운영 — 상용 검증이 끝나지 않은 CNCF 프로젝트를 직접 시험하고 국내 적용 가능성 판단
- CNCF Landscape Membership Manager — 재단 멤버십과 Landscape 등재 관리
- Developer Community Marketer — 국내 개발자 커뮤니티에 Cloud Native 기술 전파

**Multi & Hybrid Cloud R&D**

- Public Cloud와 온프레미스 OpenStack(+Kubernetes) 연결 Hybrid 아키텍처 설계
- Kubernetes Multi-Networking — EKS · AKS · GKE에 걸친 클러스터 간 네트워킹 구성 검증
- **Chaos Engineering** — Gremlin 기반으로 현대자동차 Backend 서비스의 장애 내성 검증

**한진 택배시스템 Microservice & Cloud Native 컨설팅**

- DDD · CRC 방법론으로 거대 DBMS와 **25개 업무·서비스 시스템을 8개 Domain으로 분해**, Core Domain(경로최적화) 도출
- Cloud Native 구현방안과 조직 개선점, 중장기 로드맵까지 제시
